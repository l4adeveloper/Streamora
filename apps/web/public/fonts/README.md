# Google Sans Flex

Official Google Fonts v26 WOFF2 subsets for Latin, Latin Extended, and Vietnamese.
Variable optical size 8–144; font weights 400–600; normal style and width.

Source: https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@8..144,400..600&display=swap

Project: https://github.com/googlefonts/googlesans-flex

License: SIL Open Font License 1.1, included in `OFL-Google-Sans-Flex.txt`.

The application serves these assets locally. `src/app/fonts.css` retains the
provider's Unicode ranges so accents and Vietnamese glyphs use the same family.
Latin and Vietnamese subsets are preloaded; Latin Extended loads when needed.
