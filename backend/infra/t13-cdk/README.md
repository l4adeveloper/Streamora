# T13 CDK local

Hướng dẫn đầy đủ bằng tiếng Việt: [Triển khai T13 từ máy local](../../docs/t13-cdk-local.md).

Chạy `npm run setup:t13` ở root repo. Lần đầu tạo file cấu hình để điền; lần sau
tự build, dọn service T13 tạo tay, deploy, nạp secret và bật pipeline.
Bucket nguồn `streamora-file-storage` có sẵn, chỉ được tham chiếu.
